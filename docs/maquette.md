# Maquette de l'interface – site4night

Maquette haute fidélité (couleurs, typographie, composants) réalisée dans Figma.

**Lien :**
[site4night – Maquette UI (ProgServ2)](https://www.figma.com/design/mp5zO9etWv1kmcDrRVIqOK/site4night-%E2%80%93-Maquette-UI--ProgServ2-?node-id=0-1)

## Organisation du fichier Figma

| Section                         | Contenu                                                                |
| ------------------------------- | ---------------------------------------------------------------------- |
| Composants                      | En-têtes (visiteur, utilisateur, admin), pied de page, carte de lieu   |
| Pages publiques                 | Écrans 01 à 05                                                         |
| Pages privées                   | Écrans 06 à 12                                                         |
| Fonctionnalités optionnelles    | Mes favoris, gestion des utilisateurs (hors portée initiale)           |

## Correspondance avec le cahier des charges

### Pages publiques (5)

| Écran                             | Fonctionnalités (cahier des charges) |

| 01 Accueil                        | Présentation, recherche rapide       |
| 02 Liste et recherche des lieux   | 4.2 – filtres                        |
| 03 Détail d'un lieu               | 4.2, 4.3 – fiche, avis, note moyenne |
| 04 Inscription                    | 4.1                                  |
| 05 Connexion                      | 4.1                                  |

### Pages privées (7)

| Écran                             | Fonctionnalités (cahier des charges) |
| --------------------------------- | ------------------------------------ |
| 06 Tableau de bord                | 4.1 – profil, activité               |
| 07 Modification du profil         | 4.1                                  |
| 08 Proposer un lieu               | 4.2                                  |
| 09 Mes lieux                      | 4.2 – statuts                        |
| 10 Modifier un lieu               | 4.2                                  |

### Éléments optionnels visibles dans la maquette

- Photos, carte interactive, export GPX et signalement d'un lieu (écran 03),
  marqués « optionnel ».
- Option A – Mes favoris ; Option B – Gestion des utilisateurs.
